# Reference image (local only)

Put the original hero image here (e.g. `hero-reference.webp`, 1448 × 1086).
The dev-only scene editor (`npm run dev` → `/portfolio/?editor`) loads it
automatically as an alignment overlay.

Everything in this folder except this README is git-ignored, so the reference
is never committed or deployed. You can also load any image from the editor's
"Load reference image…" button.
